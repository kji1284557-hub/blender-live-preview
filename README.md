# 블렌더 실시간 미리보기

블렌더에서 편집하면 자동으로 렌더되고, 브라우저에서 영상으로 보며 3D 구도를 조절하는 도구.

## 구조

```
블렌더(작업용) + 애드온 ── 127.0.0.1:8765 ── 브라우저(사이트)
                 └ 백그라운드 블렌더(렌더 전용, 낮은 우선순위)
```

- 모든 데이터는 작업자 PC 안에서만 오간다 (서버는 127.0.0.1 에만 열림, 외부 전송 없음).
- 렌더 캐시: `%TEMP%\blender_live_preview\<파일별 폴더>` (프레임 jpg, scene.glb, hashes.json)

## 설치 (작업자 PC마다 1회)

1. https://github.com/kji1284557-hub/blender-live-preview/releases/latest 에서 `live_preview.zip` 받기
2. 블렌더 → 편집 → 환경설정 → 애드온 → 디스크에서 설치 → 받은 zip
3. "Live Preview (실시간 미리보기)" 체크
4. 3D 뷰 사이드바(N) → **미리보기** 탭 → **미리보기 사이트 열기**

블렌더 4.1 / 5.2 에서 확인함. 블렌더를 두 개 띄우면 먼저 켠 쪽만 미리보기가 연결된다.

## 업데이트

- 작업자: 할 일 없음. 블렌더를 켤 때 새 버전이 있으면 자동으로 받아 바로 적용된다 (사이트도 함께).
  블렌더의 '온라인 접근 허용' 설정과는 별개로 동작하며, 끄려면 환경설정 → 애드온 → Live Preview → '자동 업데이트 확인'.
- 관리자: `live_preview/__init__.py` 의 `bl_info` → `"version"` 숫자를 올리고
  `python release.py "바뀐 내용"` 실행 → GitHub 릴리스가 만들어지고 끝.

## 기능

| 영역 | 내용 |
|---|---|
| 자동 렌더 | 편집이 멈추고 1.5초 뒤 렌더 시작. 현재 프레임부터 바깥으로. 새 편집이 오면 하던 렌더를 멈추고 새로 시작 |
| 바뀐 부분만 | 프레임마다 장면 상태(오브젝트 변환·본 포즈·셰이프키·카메라·라이트·가시성)를 해시로 비교해 달라진 프레임만 렌더. 상태가 같은 정지 구간은 렌더 없이 복사 |
| 전체 다시 | 메시·재질·월드·라이트 등 데이터 수정, 모디파이어·컴포지터 수정, 장면 설정(활성 카메라·출력 해상도·컬러 매니지먼트·렌더 설정·컬렉션 제외), 엔진·해상도 변경, 저장된 파일과 렌더가 일치한다고 확인할 수 없을 때(저장 안 한 편집을 버리고 다시 연 경우 등) |
| 다시 열 때 캐시 재사용 | 렌더가 끝난 뒤 편집 없이 저장한 파일은 다시 열어도 렌더를 재사용 |
| 시간에 따라 변하는 형태 | 모디파이어·시뮬레이션은 평가된 정점으로 비교, 지오노드·파티클·그리스펜슬은 매 프레임 따로 렌더. 시뮬레이션이 있으면 처음 프레임부터 순서대로 렌더 |
| 렌더 설정 | Workbench(빠름) / EEVEE / Cycles, 해상도 25~100%. 마지막 설정을 파일별로 기억 |
| 안전장치 | 컴포지터 File Output 노드는 미리보기 렌더 때 꺼서 작업 폴더를 덮지 않음. 긴 프레임 렌더 중 새 편집이 오면 렌더를 끊고 새로 시작 |
| 재생 | 재생·정지·한 프레임씩, 배속 0.25~2x, 반복, 블렌더 프레임 연동. 그림을 화면 크기로 미리 풀어 두고(작업 스레드) 재생 위치 앞쪽을 미리 준비 → 1080p 600프레임·2배속·렌더 진행 중에도 끊김 없음(측정) |
| 애니메틱 바 | 프레임별 상태 색 (초록 완료 / 주황 갱신 중 / 회색 렌더 전), 마커, 시작점 [I]·끝점 [O] 구간 |
| 영상 저장 | 구간(없으면 전체)을 mp4 로 저장 |
| 3D 구도 | 오브젝트 클릭 선택 → 이동 G / 회전 R / 크기 S. 카메라 시점(C)에서 화면을 돌리면 블렌더 카메라가 움직임. 렌즈(mm) 조절. "키프레임 찍기" 켜면 놓을 때 키 삽입. 블렌더에서 Ctrl+Z 로 되돌리기 가능 |

## 한계

- 편집 → 반영까지 수 초 (파일 복사 저장 + 렌더용 블렌더가 파일을 다시 여는 시간). 무거운 씬일수록 길어짐.
- 편집이 멈출 때 작업용 블렌더가 파일 복사본을 저장하느라 잠깐 멈춤 (무거운 씬에서 1~3초).
- 3D 화면은 구도용: 텍스처·부드러운 음영 없이 형태와 기본색만(Draco 압축, 200만 버텍스 장면도 2MB), 파티클은 안 보임, 캐릭터 변형은 렌더 시점 포즈로 고정 (오브젝트 이동은 실시간). 영상 재생 중에는 3D 모델 교체를 멈출 때까지 미룸.
- 카메라 시점 조작: 정확히 수직(바로 아래·위)을 보는 카메라는 방향이 튈 수 있음. 직교 카메라는 원근으로 표시.
- 재질 값 애니메이션, 뷰포트에서 꺼둔 오브젝트의 애니메이션, 라이트 노드 편집은 변화 감지 못 함 → "전체 다시 렌더" 버튼.
- 에디트 모드에 들어갔다 나오기만 해도 전체 다시 렌더가 돈다.
- 디스크에 베이크한 파티클·천 캐시(point cache)는 렌더용 복사본에서 찾지 못할 수 있음.
- 재생용 그림은 브라우저 메모리에 둔다(PC 메모리에 따라 0.5~4GB). 장면이 그보다 크면 재생 위치 주변만 들고 있고, CPU 가 바쁜 PC 에서는 2배속 재생이 가끔 멈칫할 수 있음.
